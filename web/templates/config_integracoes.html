Como conectar o OCR-LEITOR ao Monday

fluxo recomendado
1. Configurar

Defina as variáveis de ambiente no .env.

2. Reiniciar

Reinicie o painel web para carregar as novas variáveis.

3. Conferir

Confira nesta tela se as variáveis aparecem como CONFIGURADO.

4. Revisar

Revise os campos extraídos no detalhe do documento.

5. Simular

Use "Simular Monday" para validar antes do envio real.

6. Conferir

Confira o resultado da simulação no histórico.

7. Enviar real

Use "Enviar para Monday" somente após simulação bem-sucedida.

8. Conferir

Confira o item criado no board Monday e o histórico de integração.

⚠ Segurança: Nunca cole tokens no chat, no Git ou em documentação. Configure credenciais apenas no ambiente local seguro.
ℹ Referência: Guia completo em docs/operacao/GUIA_INTEGRACAO_OCR_MONDAY.md

Variáveis do Monday

detalhamento de cada configuração
MONDAY_API_TOKEN Token da API Monday. Gerado em Administrador → API Tokens. Mantenha em segredo.
MONDAY_BOARD_ID ID do quadro Monday. Extraído da URL: monday.com/boards/<ID>/...
MONDAY_COLUMN_EMPRESA ID da coluna da empresa/fornecedor no board.
MONDAY_COLUMN_NUMERO_NF ID da coluna do número da nota fiscal.
MONDAY_COLUMN_CHAVE_ACESSO ID da coluna da chave de acesso (44 dígitos).
MONDAY_COLUMN_VENCIMENTO ID da coluna da data de vencimento.
MONDAY_COLUMN_VALOR_TOTAL ID da coluna do valor total da nota.
MONDAY_COLUMN_OBSERVACAO ID da coluna de observações (opcional).
